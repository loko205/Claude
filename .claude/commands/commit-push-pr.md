Erstelle einen Commit mit einer aussagekräftigen Message basierend auf den aktuellen Änderungen. Nutze inline bash um zuerst `git status` und `git diff --stat` auszuführen. Dann:
1. Stage alle relevanten Änderungen
2. Schreibe eine klare, prägnante Commit-Message (auf Englisch, konventionelles Format)
3. Push zum Remote
4. Falls gewünscht: erstelle einen PR mit Zusammenfassung der Änderungen
